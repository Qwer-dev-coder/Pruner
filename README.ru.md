Pruner освобождает место на диске, убирает предустановленный мусор и отключает телеметрию и рекламу. Это один `.exe` без установщика. Программа показывает, что собирается сделать, и любую долгую операцию можно остановить.

## Возможности

| Раздел | Что делает |
| --- | --- |
| **Очистка** | Временные файлы, кэш обновлений Windows, кэш браузеров (Chrome, Edge, Brave, Opera, Яндекс, Vivaldi, Firefox), кэш Discord, Telegram и Steam, шейдеров, дампы сбоев, логи, корзина. Анализ заранее показывает, сколько места освободит каждый пункт. |
| **Приложения** | Удаляет предустановленные приложения (Xbox, Clipchamp, Solitaire, Новости, Погода, Teams и другие). Системные компоненты и Microsoft Store скрыты, их здесь удалить нельзя. |
| **Система** | 33 настройки с откатом: телеметрия, реклама, Copilot и Recall, Bing в поиске, службы, OneDrive, быстрый запуск, схема питания, классическое меню Windows 11. Защитник, SmartScreen и обновления вынесены в отдельные группы с пометкой. |
| **Автозагрузка** | Включение и отключение программ и ярлыков при старте. Ничего не удаляется. |
| **Большие файлы** | Поиск файлов от 200 МБ. Удаление отправляет файл в корзину. |
| **Настройки** | Светлая и тёмная тема, свои обои с градиентом и цветом акцента из картинки, шрифт и размер, скругление углов, плотность строк, автоочистка по расписанию. |

Ещё:

- Автоочистка через планировщик Windows (раз в неделю, день и время настраиваются).
- Перед изменением системных настроек можно создать точку восстановления.
- Необратимые действия (Windows.old, журналы событий, гибернация) всегда требуют подтверждения.
- Никакой сети, аналитики и аккаунтов. В интернет ходит только `winget`, и только если отметить эту задачу.

## Установка

1. Скачай `Pruner.exe` из [последнего релиза](https://github.com/YOUR_USER/Pruner/releases/latest).
2. Запусти и подтверди запрос прав администратора.

Требования: Windows 10 или 11 (x64) и Windows PowerShell 5.1, он есть в системе.

Проверить загрузку можно по файлу `Pruner.exe.sha256` из того же релиза:

```powershell
(Get-FileHash .\Pruner.exe -Algorithm SHA256).Hash
```

## Запуск из исходников

```powershell
powershell -ExecutionPolicy Bypass -File .\Pruner.ps1
```

Если при старте что-то пойдёт не так, появится окно с ошибкой, а подробности запишутся в `C:\ProgramData\Pruner\crash.log`.

## Сборка exe

На Linux или macOS с mingw-w64:

```sh
sudo apt install gcc-mingw-w64-x86-64 binutils-mingw-w64-x86-64
./build.sh
```

Получится `dist/Pruner.exe`: маленький запускатор, в который вшиты `Pruner.ps1` и `assets/`. Он распаковывает их в `%LOCALAPPDATA%\Pruner\app` и запускает скрипт через PowerShell. Та же сборка выполняется в GitHub Actions для каждого тега.

## О безопасности

- **Защитник.** Pruner умеет отключать Защитник Windows штатными политиками и командами. Если включена «Защита от подделки», Windows заблокирует изменение, а Pruner не будет её обходить: сначала выключи её сам в «Безопасности Windows». Отключать антивирус или нет, решаешь ты, и риск тоже твой.
- **Нет цифровой подписи.** Exe не подписан, поэтому SmartScreen может предупредить о неизвестном издателе, а некоторые антивирусы могут срабатывать на программы, меняющие настройки системы. Исходники открыты: прочитай или собери сам.
- **Сначала резервная копия.** Используй точку восстановления и проверяй список перед нажатием «Применить».
- Проект не связан с Microsoft.

## Где что лежит

| Что | Где |
| --- | --- |
| Настройки оформления | `%APPDATA%\Pruner\settings.json` |
| Журнал | `%ProgramData%\Pruner\log.txt` |
| Ошибки запуска | `%ProgramData%\Pruner\crash.log` |
| Распакованное приложение | `%LOCALAPPDATA%\Pruner\app` |
